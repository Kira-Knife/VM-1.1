## Нагрузочные тесты
Реализовано 2 теста:
1. По вставке данных <b>`POST`</b> `/api/v1/alerts`
2. По запросу данных <b>`GET`</b> `/api/v1/alerts`
### Конфигурация
В файле `main.go` измени данные на свои
```go
numberOfRequests := 100                           // число запросов
host := "https://localhost:8787"                  // хост на который пойдут запросы
```

### Запуск
Для запуска можно использовать один из подходящих вариантов
1. `go run main.go`
2. `make run`

### Результаты
Рузультат по тестам будет выведен в терминал
